# CodeBuddyTest

编程练习与工具集，包含 Python 和 JavaScript 小项目。

## Python

| 文件 | 说明 |
|------|------|
| `calc.py` | 命令行交互式计算器，支持历史记录 |
| `password_gen.py` | 密码生成器（密码学安全随机源，7 级强度评估） |
| `tree.py` | 目录树打印工具（`tree` 命令的 Python 实现） |
| `bubble_sort.py` | 冒泡排序实现 |
| `fibonacci.py` | 斐波那契数列 |
| `leap_year.py` | 闰年判断 |
| `memo.py` | 备忘录管理 |
| `temp_converter.py` | 温度转换器 |
| `guess.py` | 猜数字游戏 |
| `tcmpp_open_api_lib.py` | 腾讯云微服务平台 API 库 |

## JavaScript

| 文件 | 说明 |
|------|------|
| `csv_parser.js` | CSV 文本解析器，支持引号内逗号 |
| `todo.js` | 命令行待办事项管理器，JSON 持久化存储 |
